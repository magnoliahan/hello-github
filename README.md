# hello-github

这是我的第一个 GitHub 仓库，用于验证本机与 GitHub 的连接。

## 环境信息

| 项目 | 内容 |
| --- | --- |
| GitHub 账号 | [magnoliahan](https://github.com/magnoliahan) |
| 连接方式 | SSH（走 `ssh.github.com:443`） |
| 操作系统 | Windows 11 |
| Git 版本 | 2.56.0 |

## 说明

- 本机访问 GitHub 的 **HTTPS 通道会被重置**，因此仓库地址统一使用 SSH 格式：
  `git@github.com:magnoliahan/<仓库名>.git`
- `api.github.com` 访问稳定，可用于脚本化管理仓库。
